## Install

1. Download `ImageClassifierSetup_v{version}.exe` below and run it.
2. Windows may show a SmartScreen warning because the installer is signed with a self-signed certificate. Click **More info → Run anyway**.
3. The installer offers to trust the Image Classifier certificate. Accepting is optional but stops further warnings.

Already installed? Open **About → Check for updates** inside the app. It downloads the new version with a progress bar and restarts for you.
